# Daily-Routine
日程规划

## 项目简介
Daily-Routine 是一个简单的前端日程规划工具，帮助用户高效地管理每日任务和计划。用户可以通过网页界面添加、查看和管理自己的日常事务。

## 功能列表
- 添加每日任务/日程
- 查看任务列表
- 标记任务完成状态
- 删除任务
- 本地存储任务数据（刷新页面后依然保留）

## 使用方法
1. 打开 `index.html` 文件，即可在浏览器中使用本项目。
2. 在输入框中输入任务内容，点击添加按钮即可新增任务。
3. 点击任务旁的完成按钮可标记为已完成。
4. 点击删除按钮可移除任务。

## 文件结构说明
- `index.html`：主页面，包含任务输入和展示区域。
- `css/style.css`：页面样式文件。
- `js/app.js`：主要功能逻辑，包括任务的添加、删除、状态切换和本地存储。
